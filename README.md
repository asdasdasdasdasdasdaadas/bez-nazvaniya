# Модератор чата и комментариев

Telegram-бот для групп и обсуждений канала: личная проверка «Я не робот», антиспам, мут и бан. Рекламу включает только создатель бота.

## Что умеет

- Новый участник получает приветствие только в личку и нажимает «Я не робот». Пока кнопка не нажата, писать нельзя.
- Админы группы настраивают проверку, текст приветствия и антиспам кнопками.
- В чате есть мут, бан, кик, предупреждения и журнал.
- Создатель бота может добавить рекламу в приветствие и отдельным сообщением. На тексте стоит пометка «Реклама».

## Запуск

Из папки проекта:

```bash
chmod +x install.sh
./install.sh
```

Скрипт спросит токен и ваш id, если их ещё нет в `.env`. Дальше сам соберёт Docker и запустит бота. Если Docker не установлен, поставит зависимости в `.venv` и запустит процесс в фоне.

Перед этим в [@BotFather](https://t.me/BotFather) выполните `/setprivacy` → **Disable**. Иначе антиспам не видит обычные сообщения. Если бот уже был в группе, удалите его и добавьте снова. Свой числовой id смотрит [@userinfobot](https://t.me/userinfobot).

Ручной запуск, если скрипт не нужен. Нужен Python 3.9 или новее.

1. В [@BotFather](https://t.me/BotFather) создайте бота и скопируйте токен.
2. Выполните `/setprivacy` → **Disable**. Иначе антиспам не видит обычные сообщения. Если бот уже был в группе, удалите его и добавьте снова.
3. Узнайте свой числовой id через [@userinfobot](https://t.me/userinfobot).
4. В папке проекта:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

5. Впишите в `.env` токен и `OWNER_ID`.
6. Запустите:

```bash
python -m bot
```

Либо через Docker, из той же папки, когда `.env` уже заполнен:

```bash
docker compose up -d --build
```

База лежит в томе `bot-data` и не пропадает при пересборке. Логи: `docker compose logs -f`. Остановка: `docker compose down`. Том с базой при этом сохраняется.

Дальше откройте бота, нажмите `/start` и «Добавить в группу». Кнопка сразу просит права удалять сообщения, мутить и банить.

## Личные письма

Telegram не даёт боту первым написать человеку, который ни разу не открывал бота. Если новичок уже нажимал `/start`, письмо приходит сразу и в чате ничего не появляется. Если нет — в чате остаётся короткое «Открыть проверку», а само приветствие открывается только у него.

## Комментарии канала

Комментарии живут в группе обсуждения. Добавьте бота администратором туда, с теми же правами. Новые комментаторы проходят ту же проверку, антиспам работает и на их сообщениях.

## Команды в группе

Пишутся ответом на сообщение или с `@username`.

| Команда | Что делает |
| --- | --- |
| `/settings` | Панель в личке |
| `/mute 30m` | Мут. Без времени берётся срок из антиспама |
| `/ban 1д` | Бан. Без времени — навсегда |
| `/kick` | Исключить |
| `/unmute`, `/unban` | Снять наказание |
| `/warn` | Предупреждение |
| `/log` | Журнал |

По-русски: `/мут`, `/бан`, `/кик`, `/размут`, `/разбан`, `/варн`, `/журнал`, `/настройки`.

Время: `30m`, `2ч`, `1д`, `30 минут`, `2 часа`, `навсегда`.

Мут работает в супергруппах. Если группа обычная, включите в её настройках историю для новых участников: Telegram превратит её в супергруппу.

## Реклама

Команда `/owner` в личке с ботом. Доступна только `OWNER_ID`.

- «В приветствии» добавляет блок в личное письмо.
- «Отдельным сообщением» шлёт второе личное письмо и публикует рекламу в чат после выбранного числа пройденных проверок.
- «Отправить во все чаты» публикует текст сразу во все подключённые группы.

Админы чата это не выключают. В панели чата видно, включена ли реклама.
