# Модератор чата и комментариев

Telegram-бот для групп и обсуждений канала. Новый участник подтверждает, что он человек, кнопкой в самом чате. Пока кнопка не нажата, писать нельзя. Есть антиспам, мут, бан и реклама создателя бота.

## Что умеет

- В чат приходит одно сообщение: обращение, «подтвердите, что вы человек», свой текст приветствия, если он задан, и реклама, если она включена в проверку. Кнопки: «Я не робот» и зелёная ссылка рекламы.
- Это сообщение удаляется, когда человек нажал кнопку или когда время проверки вышло.
- В личку проверка, приветствие и реклама не отправляются. Панель настроек для админов по-прежнему в личке.
- Кто вышел или был исключён, при следующем входе проходит проверку снова. Админы чата проверку не проходят.
- Админы настраивают проверку, текст приветствия, антиспам и могут временно выключить модерацию.
- В чате есть мут, бан, кик, предупреждения и журнал.
- Рекламу задаёт только создатель бота. Подписи «Реклама» на тексте нет. Админы чата её не выключают, но видят, включена ли она.

## Запуск

Из папки проекта:

```bash
chmod +x install.sh
./install.sh
```

Скрипт спросит токен и ваш id, если их ещё нет в `.env`. Дальше сам соберёт Docker и запустит бота. Если Docker не установлен, поставит зависимости в `.venv` и запустит процесс в фоне.

Перед этим в [@BotFather](https://t.me/BotFather) выполните `/setprivacy` → **Disable**. Иначе бот не видит обычные сообщения: не работают антиспам и показ рекламы по сообщениям. Если бот уже был в группе, удалите его и добавьте снова. Свой числовой id смотрит [@userinfobot](https://t.me/userinfobot).

Ручной запуск, если скрипт не нужен. Нужен Python 3.9 или новее.

1. В [@BotFather](https://t.me/BotFather) создайте бота и скопируйте токен.
2. Выполните `/setprivacy` → **Disable**. Если бот уже был в группе, удалите его и добавьте снова.
3. Узнайте свой числовой id через [@userinfobot](https://t.me/userinfobot).
4. В папке проекта:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

5. Впишите в `.env` токен и `OWNER_ID`.
6. Запустите:

```bash
python -m bot
```

Либо через Docker, из той же папки, когда `.env` уже заполнен:

```bash
docker compose up -d --build
```

База лежит в томе `bot-data` и не пропадает при пересборке. Логи: `docker compose logs -f`. Остановка: `docker compose down`. Том с базой при этом сохраняется.

Без Docker логи пишутся в `bot.log`. Остановка: `kill $(cat .bot.pid)`.

Дальше откройте бота, нажмите `/start` и «Добавить в группу». Кнопка сразу просит права удалять сообщения, мутить и банить.

Токен и файл базы в репозиторий не входят.

## Проверка в чате

По умолчанию сообщение проверки эфемерное: оно появляется в группе, но видит его только сам новичок, у остальных лента чистая. Нужен Bot API 10.2 или новее, бот должен быть администратором. Если Telegram не принял эфемерное сообщение, бот показывает обычное, которое видят все. В настройках чата кнопка «Видит: только новичок / весь чат» переключает режим.

Telegram не гарантирует доставку эфемерных сообщений, а приложение может спрятать такое сообщение после перезапуска. Если человек не увидел проверку и время вышло, при режиме «кик» он может зайти снова и пройти её.

Кнопка «Я не робот» срабатывает только у того участника, для кого она показана. После нажатия Telegram коротко показывает «Можно писать.»

Если время вышло, бот кикает, банит или мутит — как настроено в чате — и удаляет сообщение проверки. Пока модерация выключена, бот в чате молчит и настройки сохраняет.

Мут работает в супергруппах. Если группа обычная, включите в её настройках историю для новых участников: Telegram превратит её в супергруппу.

## Комментарии канала

Комментарии живут в группе обсуждения. Добавьте бота администратором туда же, с теми же правами. Новые комментаторы проходят ту же проверку. Посты самого канала бот не модерирует.

## Команды в группе

Пишутся ответом на сообщение или с `@username`.

| Команда | Что делает |
| --- | --- |
| `/settings` | Панель в личке |
| `/mute 30m` | Мут. Без времени берётся срок из антиспама |
| `/ban 1д` | Бан. Без времени — навсегда |
| `/kick` | Исключить |
| `/unmute`, `/unban` | Снять наказание |
| `/warn` | Предупреждение |
| `/log` | Журнал |

По-русски: `/мут`, `/бан`, `/кик`, `/размут`, `/анмут`, `/разбан`, `/варн`, `/пред`, `/журнал`, `/лог`, `/настройки`, `/помощь`.

Время: `30m`, `2ч`, `1д`, `30 минут`, `2 часа`, `навсегда`.

## Реклама

Команда `/owner` в личке с ботом. Доступна только `OWNER_ID`.

Одна реклама на все чаты, куда добавлен бот. Вся реклама эфемерная: в группе её видит только тот, кому она показана. Обычных сообщений с рекламой бот не отправляет. Два места показа, их можно включать по отдельности:

- «В проверке» дописывает текст и зелёную кнопку в сообщение «Я не робот», которое видит только новичок. Если в чате включено «Видит: весь чат» или Telegram не принял эфемерное сообщение, проверка уходит обычным сообщением и рекламы в ней нет.
- «Каждому в чате» показывает рекламу человеку в момент его действия в чате: он написал сообщение, исправил его или поставил реакцию. Не больше 3 раз в день на человека (всего, во всех чатах с ботом) и не чаще раза в 2 часа. Счётчик обнуляется в полночь по Москве. Реклама в проверке тоже считается.
- Админам, владельцу и участникам с тегом или званием реклама не показывается. Тем, кто ещё не прошёл проверку, тоже.

Показ идёт в момент действия, потому что тогда человек точно в сети и сообщение почти всегда доходит. Полной гарантии доставки эфемерных сообщений Telegram не даёт, и бот не получает подтверждения, что сообщение дошло. Кто ничего не делает в чате, рекламу не получает. Реакции бот получает, только если он администратор. Об удалённых сообщениях Telegram ботам не сообщает, поэтому удаление показ не вызывает.

Публичные рекламные посты, которые бот публиковал раньше в режиме «пост каждые 150 сообщений», бот удаляет при запуске. Посты из старой кнопки «Отправить во все чаты» бот не запоминал, их нужно удалить вручную.

Чаты с выключенной модерацией пропускаются.
